Replace and refetchUndo last change
  1. Delete the old ID's stats rows in the live DB.
  2. Fetch the new ID from the API and insert its stats.
  3. Rewrite the entry in matches.json (with a backup of the previous version).
  4. Recompute the series score and redo any bracket advancement it changes.

Today's edit page renames the row and keeps the old stats (admin.py:1281), so fixing a wrong ID doesn't pull the right match's stats. This flow refetches instead.
